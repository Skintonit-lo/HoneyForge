# HoneyForge

Платформа для сбора и анализа атак с помощью honeypot и honeytoken.

## Архитектура

- **Honeypot** — фейковый веб-сервер (Flask), логирует попытки входа.
- **Honeytoken** — файл-приманка, отслеживает доступ.
- **Агент** — читает лог и отправляет данные в центр.
- **Центр** — Flask-сервер, хранит данные в SQLite.
- **Дашборд** — HTML + JS + Chart.js, отображает атаки в реальном времени.
